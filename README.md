# 🛒 Supermarket Sales Analysis

## 📌 Project Overview

This project focuses on analyzing supermarket sales data to understand sales performance, product performance, customer behavior, branch performance, payment preferences, and sales trends.

The project uses Python-based data analytics techniques to clean, analyze, visualize, and extract meaningful business insights from supermarket transaction data.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall supermarket sales performance
- Identify the highest-selling products
- Compare sales across different branches
- Analyze category-wise sales
- Understand customer purchasing behavior
- Identify the most-used payment method
- Analyze sales by gender and customer type
- Study monthly sales trends
- Analyze customer ratings
- Generate useful business insights from the data

---

## 📊 Dataset

The dataset contains supermarket sales transactions with information such as:

- Invoice ID

## 🔍 Data Cleaning

The following data preparation steps were performed:

- Checked the dataset structure
- Checked missing values
- Checked duplicate records
- Cleaned column names
- Converted the Date column into a proper date format
- Converted numerical columns into numeric data types
- Calculated sales using Quantity × Unit Price
- Checked differences between calculated and recorded sales

---

## 📈 Analysis Performed

### 1. Overall Sales Analysis

Calculated:

- Total Sales
- Total Transactions
- Total Quantity Sold
- Average Transaction Value
- Average Customer Rating

### 2. Product Analysis

Analyzed sales performance for each product and identified the highest-selling product.

### 3. Branch Analysis

Compared sales across supermarket branches to identify the branch generating the highest sales.

### 4. Category Analysis

Analyzed sales across different product categories and identified the highest-performing category.

### 5. Payment Analysis

Analyzed the number of transactions made using different payment methods.

### 6. Customer Analysis

Analyzed sales based on:

- Customer Type
- Gender
- City

### 7. Monthly Sales Analysis

Analyzed sales trends across different months to understand changes in sales performance over time.

### 8. Rating Analysis

Analyzed customer ratings and calculated the average customer rating.
